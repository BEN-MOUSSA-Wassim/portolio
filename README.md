# Wassim Ben Moussa — professional portfolio

A buildless, semantic portfolio for a GIS and Geomatics Engineer working across geospatial automation, telecommunications network data quality, and remote sensing.

## Technology

- Semantic HTML5
- Modern CSS with responsive layouts, dark/light themes, and reduced-motion support
- Dependency-free JavaScript for navigation, filtering, theme preference, scroll state, and accessible image dialogs
- GitHub Pages deployment through `.github/workflows/static.yml`

No package installation or build step is required.

## Local preview

Serve the repository root with any static HTTP server, then open the printed local URL. For example:

```powershell
python -m http.server 4173
```
